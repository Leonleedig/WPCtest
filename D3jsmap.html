📖 本平台操作說明

  • 拖曳平移 按住滑鼠左鍵並拖動畫布，即可自由平移畫面。
  • 滾輪縮放 滾動滑鼠滾輪可放大或縮小視角。
  • 固定位置 所有 API 方法已鎖定於 360 度固定角度，展開/收合時絕不改變條目位置。
  • 核心切換 點擊中央核心大圓塊，可依序「逐層全展開 / 全收合」。
  • 節點開合 點擊「圓點標誌」展開或收合分支（藍色實心點代表下方有收合分支；空心點代表已展開或終端葉節點）。
  • 自訂拖轉 按住「說明・設定」圖標即可沿內圈軌道拖曳至任意角度，並自動調校文字方向。完全收合時自動隱藏文字標籤，僅保留圖標。
  • 條目詳情 點擊任何條目文字本身，即可開啟詳情面板，查看該 API / 技術模組的詳細功能解說與 Vibe Coding 程式碼範例。

🎨 D3.js 環狀心智圖設計規範紀錄

  1. 固定 360 度空間記憶： 所有技術末端條目 (Leaves) 均分全 360 度圓周，母條目由其子樹中點決定角度。開合時角度與半徑絕對鎖定，提供直覺的空間記憶點。
  2. 「說明・設定」獨立佈局與自訂拖轉： 預設位於 5 點鐘方向（150°），以較短內圈半徑呈現。支援使用者滑鼠拖曳沿軌道旋轉至任意角度，並自動調校 4 象限文字排版；收合時自動隱藏文字標籤，獨留圖標。
  3. 階層分層半徑設定： 中央圓塊半徑 58px；「說明・設定」78px；第一層主脈 190px；第二層分類 370px；第三層語法 550px，確保文字完全不遮擋擠壓。
  4. 四象限動態文字排版：
    • 上方 (315°~45°)：垂直直排，列於節點上方。
    • 下方 (135°~225°)：垂直直排，列於節點下方。
    • 右方 (45°~135°)：水平橫排，列於節點右側。
    • 左方 (225°~315°)：水平橫排，列於節點左側。
  5. 中央核心區塊賦能： 放大為 58px 藍色圓形襯底（移除 Hover 縮放動畫），標題 28px 粗體雙行居中。點擊可切換「分層逐級全展開 / 全收合」循環。
  6. 第一級直線連接線： 第一級條目通往核心的連線採中心直線放射，平滑隱藏於中央圓形襯底下方。
  7. 獨立圖層渲染順序： 獨立連線層 (`gLinks`) 永遠在最底層，節點與文字在其之上；每次更新動態將中央核心點提升至最頂層 (`raise()`)。
  8. 節點開合狀態指標： 藍色實心點代表下方有收合的子分支；空心點代表已展開或終端葉節點。
  9. 點按文字觸發詳情面板： 劃分圓點與文字的互動權責——點擊「圓點/圖標」專注於控制層級分支開合與拖曳；點擊「條目文字」則觸發詳情面板。
  10. 雙重配色模式（通用／分組）： 提供預設通用藍/灰配色與「分組色彩模式」。切換為分組配色時，系統會為每個一級主脈（包含連線、圓點與文字標籤）配發獨立主題色。
